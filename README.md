# Калах (Kalah) — настольная игра

**Роль:** Системный аналитик  
**Статус:** Анализ завершён, разработка в процессе 

Проект выполняется **«под ключ»**: от бизнес-анализа до работающего приложения.

---

## Содержание документации

| Артефакт | Описание |
|----------|----------|
| Техническое задание | 5 разделов: объект автоматизации, требования к ИО, ТО, ПО |
| Анализ 3 аналогов | Mancala, Mancala Online, Манкала |
| Диаграмма объектов | 7 сущностей: Игрок, Игра, Доска, Лунка, Калах, Статистика, Результат |
| Диаграмма use cases | 1 актор, 8 вариантов использования |
| Структурная схема | 8 подсистем (регистрация, ИИ, визуализация, БД и др.) |
| Навигационная модель | Карта переходов между 8 экранами |
| Прототипы интерфейса | 8 экранов: регистрация, настройки, игра (2 темы), статистика |
| Модель данных | SQLite: Players, Games, Statistics, DifficultyLevels |
| Use case спецификации | Основные + альтернативные потоки |

## Ключевые артефакты

### 1. Бизнес-правила 
| Правило | Значение |
|---------|----------|
| Длина имени | 4-8 символов |
| Количество аватаров | 10 |
| Лунок на стороне | 6-8 |
| Камней в лунке | 4-6 |
| Уровней сложности бота | 3 |

### 2. Функции системы 
- Создание доски по параметрам
- Проверка выбора лунки
- Пересчёт камней
- Определение дополнительного хода
- Определение победителя
- Формирование статистики
- Визуализация + звуковые эффекты

### 3. Технологический стек

| Компонент | Технология |
|-----------|------------|
| Язык | Kotlin 2.3.10 |
| IDE | Android Studio 2025 |
| СУБД | SQLite 3.51.2 |
| Проектирование | StarUML 7.0.0 |
| Игровая логика | Kotlin |
| ИИ противника | Minimax (3 уровня) |
| Интерфейс | Android XML, 2 темы |
| Звук | MP3-эффекты |
| Целевая ОС | Windows 10+ / Android |
