## 1. Структурная схема

Система декомпозирована на следующие подсистемы:

| Подсистема | Назначение |
|------------|------------|
| **Регистрация** | Создание и ведение учётных записей пользователей |
| **Настройки игры** | Конфигурирование параметров: лунки, камни, звук, оформление, режим игры, сложность бота |
| **Ведение игры** | Управление игровым процессом |
| └ *ИИ* | Принятие решений компьютерным противником (3 уровня сложности) |
| └ *Локальная игра* | Проведение партии между двумя игроками на одном устройстве |
| └ *Управление процессом* | Обработка правил, контроль состояния игры |
| **Визуализация** | Графическое отображение доски, лунок, камней и счёта |
| **Справочная подсистема** | Правила игры, информация о разработчиках |
| **Статистика** | Сбор и отображение информации о сыгранных партиях |
| **Взаимодействие с БД** | Управление базой данных (SQLite) |
| **База данных** | Хранение данных об игроках, партиях и статистике |

## 2. Навигационная модель

Навигационная модель описывает переходы между экранами приложения:

| Экран | Переходы |
|-------|----------|
| Главное меню | → Настройки, → Статистика, → Об игре, → Регистрация |
| Настройки | → Главное меню |
| Статистика | → Главное меню |
| Об игре | → Главное меню |
| Регистрация | → Новая игра |
| Новая игра | → Игровое поле |
| Игровое поле | → Главное меню (завершение игры) |

*Подробная навигационная модель представлена на рисунке 21.*
