# Бизнес-правила игры «Калах»

## Категории правил

1. **Регистрация** — правила создания учётной записи
2. **Игровая механика** — правила хода, захвата, окончания игры
3. **Режимы и настройки** — выбор режима, сложности, оформления

---

## 1. Правила регистрации

| ID | Правило | Значение |
|----|---------|----------|
| BR-01 | Минимальная длина имени | 4 символа |
| BR-02 | Максимальная длина имени | 8 символов |
| BR-03 | Количество доступных аватаров | 10 |
| BR-04 | Уникальность имени | Имя не должно повторяться |

---

## 2. Правила игровой механики

| ID | Правило | Значение |
|----|---------|----------|
| BR-05 | Количество игроков | 2 |
| BR-06 | Количество калахов | 2 |
| BR-07 | Минимальное количество лунок на стороне | 6 |
| BR-08 | Максимальное количество лунок на стороне | 8 |
| BR-09 | Минимальное исходное количество камней | 4 |
| BR-10 | Максимальное исходное количество камней | 6 |
| BR-11 | Посев камней | Против часовой стрелки |
| BR-12 | Запрет на калах соперника | Камни не кладутся в калах противника |
| BR-13 | Дополнительный ход | Если последний камень попал в свой калах |
| BR-14 | Захват | Если последний камень попал в свою пустую лунку |
| BR-15 | Окончание игры | Все лунки одного игрока пусты |

---

## 3. Правила режимов и настроек

| ID | Правило | Значение |
|----|---------|----------|
| BR-16 | Количество режимов игры | 2 (PvP / PvE) |
| BR-17 | Количество видов оформления доски | 2 («Дерево», «Металл») |
| BR-18 | Количество уровней сложности бота | 3 |
| BR-19 | Формат звуковых эффектов | MP3 |
| BR-20 | Минимальное разрешение экрана | 800×600 |
