# Анализ систем-аналогов

## Обзор

Для анализа существующих решений были выбраны три мобильных приложения, реализующих механику игры «Калах»:

1. **Mancala** (AlignIt Games)
2. **Mancala Online – Congklak** (DonkeyCat Games)
3. **Манкала** (AppOn Innovate)

Выбор обусловлен их популярностью среди пользователей и различиями в реализованном функционале.

---

## 1. Mancala (AlignIt Games)

### Основные характеристики

| Параметр | Описание |
|----------|----------|
| **Разработчик** | AlignIt Games |
| **Режимы игры** | Против ИИ, вдвоём на одном устройстве, онлайн |
| **Настройки поля** | Фиксированные (6 лунок, 4 камня) |
| **Кастомизация** | Отсутствует |
| **Звук** | Есть |
| **Оформление** | Яркие тона, горизонтальная доска |

### Достоинства
- Три режима игры (PvP, PvE, онлайн)
- Интуитивный интерфейс
- Плавная анимация
- Обучающий режим для новичков

### Недостатки
- Нет возможности изменить параметры доски
- Нет кастомизации внешнего вида
- Нет функции отмены хода

## 2. Mancala Online – Congklak (DonkeyCat Games)

### Основные характеристики

| Параметр | Описание |
|----------|----------|
| **Разработчик** | DonkeyCat Games |
| **Режимы игры** | Онлайн, с ИИ, вдвоём на одном устройстве |
| **Настройки поля** | Фиксированные (6 лунок, 4 камня) |
| **Кастомизация** | Отсутствует |
| **Звук** | Есть |
| **Оформление** | Спокойные серые тона, вертикальная доска |

### Достоинства
- Обширная система рейтингов
- Красивая визуализация
- Большое количество онлайн-соперников

### Недостатки
- Неполная реализация правил (ограничение на первый ход для бота)
- Отсутствие обучения для новых игроков
- Перегруженность интерфейса рекламой

## Выводы

Проведённый анализ показал, что существующие приложения реализуют базовый набор функций игры «Калах», однако ни одно из них не сочетает в себе одновременно:

1. **Качественную кастомизацию** внешнего вида
2. **Возможность изменения настроек игрового поля** (количество лунок и камней)
3. **Полноценное звуковое сопровождение**

### Уникальное торговое предложение (УТП) разрабатываемой системы

| Особенность | Описание |
|-------------|----------|
| **Гибкие настройки доски** | Возможность выбрать 6-8 лунок и 4-6 камней |
| **Кастомизация** | 2 темы оформления («Дерево», «Металл») |
| **Звуковое сопровождение** | MP3-эффекты (ход, захват, победа) |
| **Офлайн-работа** | Полная автономность, интернет не требуется |
