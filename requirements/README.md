## Источники требований

Требования сформированы на основе следующих источников:

1. **Техническое задание** — утверждённый документ с исходными данными
2. **Правила игры «Калах»** — классические правила настольной игры
3. **Анализ аналогов** — сравнение существующих приложений

---

## Структура требований

### Функциональные требования (FR)
Описывают, что система должна делать:
- Регистрация пользователей
- Создание игры с настройками
- Игровой процесс (ход, захват, доп. ход)
- Визуализация и звук
- Статистика

### Нефункциональные требования (NFR)
Описывают, какой должна быть система:
- Аппаратные требования (800×600, мышь)
- Программные требования (Windows 10+, Chrome/Firefox)
- Условия эксплуатации (температура, влажность)

## Бизнес-правила

Ключевые ограничения из ТЗ:

| Правило | Значение |
|---------|----------|
| Длина имени | 4-8 символов |
| Количество аватаров | 10 |
| Лунок на стороне | 6-8 |
| Камней в лунке | 4-6 |
| Режимы игры | 2 (PvP / PvE) |
| Уровни сложности | 3 |
| Оформление доски | 2 темы |
