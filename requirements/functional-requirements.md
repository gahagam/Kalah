# Функциональные требования

## Обозначения

- **FR** — Functional Requirement
- **Приоритет:** Высокий / Средний / Низкий

---

## FR-01: Регистрация пользователя

| Поле | Значение |
|------|----------|
| **Описание** | Пользователь создаёт учётную запись |
| **Приоритет** | Высокий |
| **Входные данные** | Имя (4-8 символов), выбор аватара (1 из 10) |
| **Выходные данные** | Учётная запись сохранена в БД |
| **Критерий приёмки** | Имя уникально, соответствует длине, аватар выбран |

---

## FR-02: Создание новой игры

| Поле | Значение |
|------|----------|
| **Описание** | Пользователь настраивает параметры игры |
| **Приоритет** | Высокий |
| **Параметры** | Количество лунок (6-8), камней (4-6), режим (PvP/PvE), сложность (1-3) |
| **Критерий приёмки** | Доска создана с заданными параметрами, запись в БД |

---

## FR-03: Выполнение хода

| Поле | Значение |
|------|----------|
| **Описание** | Игрок выбирает лунку, система выполняет посев камней |
| **Приоритет** | Высокий |
| **Правила** | Посев против часовой стрелки, пропуск калаха соперника, захват, дополнительный ход |
| **Критерий приёмки** | Камни распределены корректно, счёт обновлён |

---

## FR-04: Определение победителя

| Поле | Значение |
|------|----------|
| **Описание** | Система определяет окончание игры и победителя |
| **Приоритет** | Высокий |
| **Условие окончания** | Все лунки одного игрока пусты |
| **Результат** | Камни соперника переходят в его калах, сравнение счёта |

---

## FR-05: Формирование статистики

| Поле | Значение |
|------|----------|
| **Описание** | Сохранение результатов игры |
| **Приоритет** | Средний |
| **Сохраняемые данные** | Игроки, тип игры, результат |
| **Критерий приёмки** | Статистика отображается на экране статистики |

---

## FR-06: Визуализация доски

| Поле | Значение |
|------|----------|
| **Описание** | Отображение игрового поля |
| **Приоритет** | Высокий |
| **Темы** | «Дерево», «Металл» |
| **Критерий приёмки** | Корректное отображение лунок, камней, счёта |

---

## FR-07: Звуковое сопровождение

| Поле | Значение |

| **Приоритет** | Средний |

## FR-08: Справочная информация
