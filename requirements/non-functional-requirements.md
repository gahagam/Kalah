# Нефункциональные требования

## 1. Требования к техническому обеспечению

| Компонент | Требование |
|-----------|------------|
| Тип ЭВМ | IBM PC совместимый |
| Процессор | Intel Pentium 1.5 ГГц и выше |
| ОЗУ | Не менее 3 ГБ |
| Дисковое пространство | Не менее 25 ГБ |
| Монитор | Разрешение не ниже 800×600 пикселей |
| Управление | Мышь |
| Дополнительно | Клавиатура или иное устройство ввода |

---

## 2. Требования к программному обеспечению

### 2.1 Клиентская часть

| Компонент | Требование |
|-----------|------------|
| Операционная система | Windows 10 и выше |
| Браузер | Google Chrome 86+, Firefox 83+ |
| Дополнительно | Qt framework 5.11+ (при необходимости) |

### 2.2 Рабочее место разработчика

| Компонент | Требование |
|-----------|------------|
| Операционная система | Windows 10 и выше |
| Язык программирования | Kotlin 2.3.10 |
| Среда разработки | Android Studio 2025 |
| СУБД | SQLite 3.51.2 |
| Средство проектирования | StarUML 7.0.0 |

## 3. Требования к условиям эксплуатации

| Параметр | Требование |
|----------|------------|
| Температура окружающего воздуха | 15-35°С |
| Влажность воздуха | 45-75% |
| Санитарные нормы | СанПин 2.2.2./2.4.2198-07 |
| Содержание вредных веществ | По ГОСТ 12.1.005 |
| Подвижность воздуха | По ГОСТ 12.01.007 |

---

## 4. Требования к режиму работы

| Параметр | Требование |
|----------|------------|
| Режим работы | Диалоговый (интерактивный) |
| Время отклика | Мгновенный (для игровых действий) |
| Доступность | Офлайн, интернет не требуется |

---

## 5. Требования к безопасности данных

| Параметр | Требование |
|----------|------------|
| Целостность БД | Обеспечена (внешние ключи, ограничения) |
| Защита от НСД | Локальное хранение, без сетевого доступа |
| Резервное копирование | Не требуется (локальное приложение) |

---

## 6. Требования к производительности

| Параметр | Требование |
|----------|------------|
| Запуск приложения | Не более 5 секунд |
| Выполнение хода | Не более 0.5 секунды |
| Работа ИИ | Не более 2 секунд (зависит от уровня сложности) |
| Память | Не более 100 МБ ОЗУ в процессе работы |

---

## 7. Требования к интерфейсу

| Параметр | Требование |
|----------|------------|
| Язык интерфейса | Русский |
| Шрифты | Читаемые, не менее 12pt |
| Адаптивность | Поддержка разрешений от 800×600 до 1920×1080 |
