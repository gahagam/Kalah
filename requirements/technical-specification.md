# Техническое задание

## 1. Характеристика объекта автоматизации

| № | Параметр | Значение |
|---|----------|----------|
| 1 | Объект автоматизации | Игра «Калах» |
| 2 | Виды автоматизируемой деятельности | Регистрация, создание игры, ведение игры, визуализация |
| 3 | Минимальная длина имени | 4 символа |
| 4 | Максимальная длина имени | 8 символов |
| 5 | Количество аватаров | 10 |
| 6 | Количество игроков | 2 |
| 7 | Количество калахов | 2 |
| 8 | Минимальное количество лунок (на одной стороне) | 6 |
| 9 | Максимальное количество лунок (на одной стороне) | 8 |
| 10 | Минимальное исходное количество камней в лунке | 4 |
| 11 | Максимальное исходное количество камней в лунке | 6 |
| 12 | Количество режимов игры | 2 (PvP / PvE) |
| 13 | Количество видов оформления доски | 2 |
| 14 | Количество уровней сложности | 3 |

## 2. Требования к информационному обеспечению

### 2.1 Источники информации
- [Калах (Википедия)](https://ru.wikipedia.org/wiki/Калах)
- [Правила игры Калах](https://kalah.ru/rules)

### 2.2 Форматы данных
- Звуковые эффекты: MP3

### 2.3 Структура базы данных

| Сущность | Атрибуты |
|----------|----------|
| Игрок | имя, аватар |
| Игра | тип игры, результат |
| Уровень сложности бота | номер уровня, глубина поиска, задержка реакции, допустимое количество ошибок |
| Статистика | имя игрока, список побед и поражений |

### 2.4 Требования к БД
- Обеспечение целостности данных
- Защита от несанкционированного доступа

## 5. Общие требования к системе

### 5.1 Функции системы

**Функции системы:**
- Создание игровой доски по заданным параметрам
- Проверка выбора лунки
- Пересчёт количества камней в лунках
- Определение дополнительного хода
- Определение победителя
- Формирование статистики
- Визуализация доски
- Воспроизведение звуковых эффектов
- Выдача справочной информации

**Функции игрока:**
- Регистрация (имя, аватар)
- Создание игры (лунки, камни, режим, сложность)
- Выбор лунки (ход)
- Настройка оформления
- Настройка звука
- Просмотр статистики
- Просмотр справочной информации
